## 製品概要
### 背景(製品開発のきっかけ、課題等）
現代では、アニメや音楽、書籍といったカルチャーは世代や属性を超えて楽しまれています。それに伴い、「同じ好きを共有できる誰かと繋がりたい」という欲求は日に日に高まっています。しかし、既存のSNSでは、繋がるためにまず自分の趣味嗜好リストを不特定多数に"自己開示"する必要がありました。
「これを好きだと思われるのは嬉しいが、あれを好きだと知られるのは少し恥ずかしい」
「こんなに沢山見ている（or 少ししか見ていない）と知られたくない」
この「自己開示のジレンマ」は、多くの人にとって繋がりを求める上での障壁となっています。特に、自身の状況を公言しづらいマイノリティの方々や、同じ境遇の仲間を探している難病患者の方々にとって、この障壁はより高く、深刻な孤立に繋がりかねない課題です。
### 製品説明（具体的な製品の説明）
SecetSyncは、「プライバシー」と「共感」を両立させる、新しい形の繋がりを提供するサービスです。ユーザーは自身の趣味や関心事（好きなアニメ、読んだ本、応援するアーティスト、さらには指定難病などのデリケートな情報まで）をリストとして登録します。秘密計算技術により、このリストは他人だけでなく、私たち運営サーバーにさえも生の形で知られることは決してありません。
そして、他のユーザーとリストを照合した際、「両者に共通する項目」だけが安全に抽出され、双方に開示されます。これにより、互いの違いやリストの全体像を知ることなく、共通の接点だけをきっかけに安心して繋がることが可能になります。
### 特長
#### 1. 特長1.絶対的なプライバシー保護
秘密計算技術を用いることで、ユーザーの登録リストはサーバー上でさえ暗号化されたまま照合されます。第三者はもちろん、運営管理者もユーザーの生のリストを見ることはできません。「誰かに見られるかもしれない」という不安を、技術的に解消します。
#### 2. 特長2.「共通点」だけが繋がりのきっかけに
照合結果として表示されるのは、お互いが共通して登録した項目のみです。「片方だけが好きなもの」や「登録数の多寡」といった、比較や評価に繋がりかねない情報は一切伝わらないため、安心して全趣味を登録できます。
